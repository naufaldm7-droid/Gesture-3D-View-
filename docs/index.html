Plugin AutoCAD · Windows 10/11 · gratis & open source

Kendalikan AutoCAD dengan gerakan tangan

Kamera laptop membaca tangan Anda untuk menggerakkan kursor, klik, memutar, menggeser, dan men-zoom model 3D, serta membuka menu perintah. Tidak perlu memasang Python.

Pasang dalam 3 langkah

Unduh & jalankan

Klik Download, lalu buka GestureControl-Setup.exe → Next → Install. Tidak perlu hak admin.

Buka AutoCAD

Buka (atau mulai ulang) AutoCAD. Bila muncul peringatan keamanan untuk GestureControl.lsp, pilih Always Load.

Ketik GK

Kamera gestur menyala. Ketik GK lagi, atau klik ✕ Tutup, untuk mematikan.

Gestur

☝TelunjukKursor seperti mouse: gerak pelan = presisi, cepat = jauh, diam = terkunci
🤏JepitLepas = klik · geser = drag · tahan 0,8 detik = klik kanan
✊ ✌ 🤟Orbit · pan · zoom (naik/turun)
✊✊Dua kepalanPutar tampilan 3D seperti memegang model; rentangkan tangan = zoom halus
🤏🤏Dua cubitanGeser tampilan; rentangkan = zoom
👍👎🤘TahanEnter · Undo · Esc
🤙TahanMenu kaca berisi perintah: 2D, Solid, Edit, View, Window, dan lainnya
🖐TelapakBerhenti, atau "angkat mouse" untuk memindah tangan

Pertanyaan umum

Windows menampilkan "Windows protected your PC"

Penginstal belum bertanda tangan digital, jadi SmartScreen memperingatkan. Klik More info → Run anyway. Kode sumbernya terbuka di GitHub untuk diperiksa siapa saja.

Overlay menulis "Kamera gelap / tertutup" atau "Tidak ada kamera asli"

Kamera laptop sedang dimatikan oleh penutup atau tombol privasi (sering F8/F9 berikon kamera, atau pengaturan Camera Privacy di aplikasi bawaan laptop), atau webcam USB tidak tersambung. Aktifkan kamera, lalu ketik GK dua kali.

Gerakan terasa lambat

Lihat angka fps di kartu kamera. Di ruangan redup, webcam otomatis turun ke ~15 fps. Tambah cahaya dari arah depan.

Bagaimana cara melepas plugin?

Settings → Apps → Gesture Control untuk AutoCAD → Uninstall.

Bisa disetel kecepatannya?

Bisa. Semua kecepatan dan ambang ada di config.json; panduannya di docs/tuning.md.

Privasi: gambar kamera diproses hanya di komputer Anda. Tidak ada gambar atau data yang dikirim ke internet.
